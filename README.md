# Yoku — landing page

Single-screen landing page for Yoku (penetration testing), in English and Spanish.

- `docs/` — the deployed static site (GitHub Pages serves this folder): `index.html` (EN), `es/index.html` (ES).
- `*.dc.html`, `canvas.json` — the design-canvas artboards the site was built from.
- `archive/` — the earlier multi-section version and an alternate hero.
- `chroma-labs/` — a separate single-screen landing for Chroma Labs (living moss scene in Three.js); see its own README.

The hero sphere is an original Canvas 2D glyph sphere: hover to spin it faster, click to knock glyphs loose.
