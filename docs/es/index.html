Fallo de autorización a nivel de objeto en la exportación de facturas

GET /api/v2/invoices/{id}/export

Cualquier usuario autenticado puede descargar facturas de otros tenants cambiando el id. Los ids son secuenciales: toda la base de clientes puede enumerarse.

— Reproducción 1. Autentícate como tenant A 2. Pide la factura 48213 (tenant B) 3. El servidor devuelve el PDF del tenant B — 200 OK
— Corrección Exigir verificación de propiedad del lado del servidor en cada acceso.
