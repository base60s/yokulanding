CRITICAL CVSS 9.1 CWE-639

Broken object-level authorization on invoice export

GET /api/v2/invoices/{id}/export

Any authenticated user can download invoices belonging to other tenants by changing the numeric id. Ids are sequential, so the full customer base can be enumerated in under an hour.

— Reproduction 1. Authenticate as tenant A, capture the session token 2. Request /api/v2/invoices/48213/export (tenant B) 3. Server returns tenant B's invoice PDF — 200 OK
— Fix Enforce an ownership check server-side on every object access. Move to non-sequential ids as defence in depth.
